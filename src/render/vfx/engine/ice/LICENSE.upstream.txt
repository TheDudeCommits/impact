Third-party notices for src/render/vfx/engine/ice/ (Jump Engine VOL.2, the ICE element kit)

Code in this folder is adapted from three MIT-licensed repositories in the owner's VFX Armory
(https://threejs-vfx-sandbox.vercel.app). Each file names what it adapts in its header. Nothing is copied
wholesale: the shapes, layouts, timings and shading ideas were ported to TypeScript, to unlit ShaderMaterials,
to the game's shared noise texture, pooled instance batches and the engine's effect contract. No textures,
models, HDRs, animations or audio from these repositories are used.

1. HandCastAbilityThreeJS - https://github.com/achrefelouafi/HandCastAbilityThreeJS
   Pinned commit 3431252f7ad88059681d4b9b6484cb7483f7d0d6
   Adapted: src/assets/GlacialGeometry.js (createGlacialCoreGeometry -> geometry.ts glacialCore),
   src/materials/ShardCrystalMaterial.js (crystal shading ideas -> materials.ts),
   src/materials/GlacialSpine.js (the stateless wake -> IceLance.ts, IcePheasant.ts),
   src/effects/IceStatue.js (freeze, hold, break along the seams -> FreezeOnHit.ts).
